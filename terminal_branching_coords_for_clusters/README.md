# Terminal Branch Statistics

This folder contains utilities for computing and storing terminal branch statistics used by the clustering module.

## Overview

Terminal branches are dendritic segments that have no child segments (i.e., they are leaf nodes in the dendritic tree). These branches are identified and their spatial properties (center coordinates, length) are computed for use in organizing synapses into functional groups.

## Active Files

### `get_terminal_branch_stats.py`
**Purpose**: Computes terminal branch statistics from segment_data.csv

**Function**: `get_terminal_branch_statistics(segment_csv_path)`
- Reads segment_data.csv from a simulation directory
- Identifies terminal segments (segments not listed as parent segments)
- Calculates center coordinates and total length for each terminal segment
- Groups by section type (tuft, distal_basal, oblique, trunk, nexus, perisomatic)
- Returns dict: `{sec_type: {seg_id: {'center_coords': (x,y,z), 'total_length': float}}}`

**Usage as script**:
```python
# Edit the sim_dir path in __main__ section, then run:
python get_terminal_branch_stats.py
```
This generates `terminal_branch_statistics.py` in the specified simulation directory.

**Usage as module**:
```python
from terminal_branching_coords_for_clusters.get_terminal_branch_stats import get_terminal_branch_statistics

branch_stats = get_terminal_branch_statistics("path/to/segment_data.csv")
```

### `terminal_branch_statistics.py`
**Purpose**: Pre-computed terminal branch statistics (auto-generated)

This file is generated by `get_terminal_branch_stats.py` and contains a single variable `branch_stats` with the terminal branch data. It is imported by `Modules/clustering.py` as the default branch statistics.

**Structure**:
```python
branch_stats = {
    'tuft': {
        2016: {'center_coords': (-54.61, 983.56, -62.58), 'total_length': 497.83},
        2179: {'center_coords': (12.45, 1030.49, -20.27), 'total_length': 362.37},
        ...
    },
    'distal_basal': {...},
    'oblique': {...},
    ...
}
```

## Archived Files

The `archive/` folder contains legacy branch statistics files that are no longer used:
- `branch_statistics.py` - Old format, only tuft branches
- `branch_statistics_combined.py` - Combined format without section type organization
- `all_branch_statistics.py` - Experimental file, never completed

These are kept for reference but superseded by the current `terminal_branch_statistics.py` format.

## Workflow

1. Run a simulation that generates `segment_data.csv`
2. Run `get_terminal_branch_stats.py` to compute terminal branch statistics
3. Generated `terminal_branch_statistics.py` is used by `Modules/clustering.py`
4. Clustering module organizes synapses into functional groups based on terminal branch locations

## Notes

- Terminal branches are identified as segments with no children (not in the parent segment list)
- Currently treats each terminal segment as its own "branch" (could be extended to group multiple segments)
- Coordinates are rounded to 2 decimal places for consistency
- Statistics are organized by `sec_type_precise` from segment_data.csv
